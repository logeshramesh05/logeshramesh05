**Jul 2026 – Present**

> *Building infrastructure to test and benchmark AI agents in real-world software engineering environments*

### ⚡ **Zoho Corporation** | *Software Engineering Intern (On-site – Chennai, India)*
**Feb 2026 – May 2026**

> *Built a hybrid data generation engine powering 30M+ records across analytics platforms*

- 🧠 Designed a **hybrid LLM + Java Faker** data generation engine to overcome LLM latency/scale limits, generating **30M+ rows** across **Zoho Analytics** and **ManageEngine Analytics Plus** with low latency

- 🔧 Built a **5-strategy JSON repair pipeline** to fix broken LLM outputs and extended the generator to **9 global datacenter regions** with region-specific OAuth2 credentials and token flows
